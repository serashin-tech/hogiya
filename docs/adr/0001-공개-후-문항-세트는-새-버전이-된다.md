# 공개 후 문항 세트는 새 버전이 되고, 시도는 제출 당시 버전에 남는다

공개한 문항 세트나 루브릭을 교사가 고치면 기존 것을 덮어쓰지 않고 새 버전을 만들며, 이미 낸 시도는 제출 당시의 버전에 연결된 채로 둔다. 공개 후 수정을 금지하면 오타 하나도 고치지 못하고, 기존 시도를 새 기준으로 다시 채점하면 학생이 본 결과가 나중에 바뀌어 교사가 근거를 확인할 수 없기 때문이다.

## Consequences

- 대시보드의 수준별 분포는 시도가 연결된 버전을 기준으로 계산한다. 같은 수업에 버전이 여럿이면 집계 화면에 어느 버전의 결과인지 보여야 한다.
- 문항 세트와 루브릭은 처음부터 버전 단위의 데이터로 설계한다.
