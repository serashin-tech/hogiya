# 기록의 단위는 시도이고, 집계는 학생별 최근 시도 기준이다

학생이 한 수업의 선진단을 여러 번 할 수 있으므로 기록의 단위를 학생이 아니라 시도로 둔다. 수준별 분포와 재지도 대상 개념은 학생마다 가장 최근 시도로 계산하고, 참여 횟수만 모든 시도를 합산한다. 학생당 한 번만 허용하면 구조는 단순하지만 복습 뒤 다시 설명해 보기와 이후 성장 기록을 담을 수 없어서, 처음부터 시도를 쌓는 구조로 시작한다.

## Consequences

- 같은 요청이 다시 와도 한 시도로만 기록되도록 시도마다 구별 가능한 값이 필요하다.
- 학생이 다시 풀어서 수준이 오르면 대시보드의 분포가 즉시 바뀐다. 과거 시도의 수준은 조회할 수 있어야 한다.
