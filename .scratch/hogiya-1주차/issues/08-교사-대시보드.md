# 08: 교사 대시보드

**What to build:** 교사가 담당 과목 수업별로 참여 횟수(모든 시도의 합), 수준별 분포(학생마다 최근 시도 기준으로 개념별 세 단계의 인원), 재지도 대상 개념("더 알아봐요" 인원이 많은 순서의 개념 목록)을 봅니다. 학급 전체 화면에는 분포와 개념 목록만 보이고, 개인 답안은 개념이나 문항을 눌러 내려가야 열립니다. 내려가면 학생 번호, 선택, 이유 문장, 판단 근거를 볼 수 있고 학생 이름은 없습니다. 대시보드가 보여 주는 문항 세트 버전을 표시합니다. 합성 시도 데이터를 기대 집계와 함께 두어 화면의 값과 비교합니다. 시도가 없는 수업에는 "아직 선진단을 한 학생이 없어요"를 보여 줍니다. 담당이 아닌 수업의 대시보드는 열리지 않습니다. 집계 계산은 화면과 분리한 함수로 두고 단위 테스트를 먼저 씁니다. ADR 0002. Spec: S07.

**Blocked by:** 06

**Status:** done

- [x] 합성 데이터로 계산한 참여 횟수, 수준별 분포, 재지도 대상 개념이 기대 집계와 일치한다.
- [x] 한 학생이 두 번 시도하면 분포에는 최근 시도만, 참여 횟수에는 두 번이 모두 반영된다.
- [x] 학생이 새 시도를 제출하면 대시보드의 분포가 즉시 바뀐다.
- [x] 학급 전체 화면에서 개인 이름이나 번호가 보이지 않고, 내려간 화면에는 이름 없이 번호만 보인다.
- [x] 이유 문장이 개인 답안 화면에서 교사에게 보인다.
- [x] 대시보드에 문항 세트 버전이 표시된다.
- [x] 시도가 없는 수업에는 안내 문구가 나온다.
- [x] 담당이 아닌 수업의 대시보드 주소를 직접 열면 거절된다.
