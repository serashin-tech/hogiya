# 03: 문항 세트와 루브릭 등록, 수업 공개와 마감

**What to build:** 교사가 수업에 선진단 5문항(지문, 선택지, 정답, 이유 칸 유무, 연결 개념, 루브릭)과 개념별 확인 활동 안내 한 줄을 입력합니다. 문항이 정확히 5개이고 각 문항에 정답, 개념, 루브릭이 있으며 확인 활동 안내가 갖춰질 때만 수업을 공개할 수 있고, 부족하면 항목별로 무엇이 부족한지 알려 줍니다. 공개하면 학생의 수업 목록에 나타나고, 마감하면 새 시도가 막히지만 이전 결과는 계속 보입니다. 마감은 다시 공개로 되돌릴 수 있습니다. 문항 하나는 개념 하나에만 연결하고, 개념 하나에는 문항 여러 개를 연결할 수 있습니다. Spec: S02(공개 상태), S03.

**Blocked by:** 02

**Status:** done

- [x] 문항이 4개이면 공개가 거절되고 "문항 1개가 더 필요합니다"가 표시된다.
- [x] 정답이 선택지에 없으면 저장되지 않는다.
- [x] 문항 하나에 개념을 둘 이상 연결하려 하면 막힌다.
- [x] 공개하면 6학년 2반 학생 전원의 수업 목록에 나타난다.
- [x] 마감한 수업에서 학생이 선진단을 시작하려 하면 막히고, 마감 전 시도의 결과는 계속 조회된다.
- [x] 마감한 수업을 다시 공개할 수 있다.
- [x] 공개 조건 검사는 화면과 분리한 함수로 두고 단위 테스트가 있다.
