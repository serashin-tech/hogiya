# 05: 학생의 선진단 제출

**What to build:** 학생이 공개된 수업의 5문항에 답하고 제출합니다. 선택은 필수이고, 이유 칸이 있는 문항의 이유 문장은 선택 입력입니다. 제출마다 시도 키를 만들어 함께 보내며, 같은 학생이 같은 시도 키로 다시 요청해도 시도는 한 번만 기록됩니다. 같은 학생이 새로 풀기를 하면 새 시도 키로 새 시도가 쌓이고 횟수 제한은 없습니다. 제출이 실패해도 입력한 답은 화면에 남습니다. 01번의 시드 수업으로 시험하므로 교사 쪽 티켓을 기다리지 않습니다. 결과와 복습 화면으로 이동하는 부분은 06번에서 만듭니다. ADR 0002. Spec: S04.

**Blocked by:** 01

**Status:** done

- [x] 한 문항을 비우고 제출하면 막히고, 첫 미응답 문항으로 이동해 그 문항이 강조된다.
- [x] 같은 시도 키로 두 번 제출해도 시도는 한 번만 기록된다.
- [x] 같은 학생이 새로 풀기를 눌러 제출하면 시도가 2개가 되고 참여 횟수가 2가 된다.
- [x] 제출 처리가 실패해도 입력한 답이 화면에 남고 다시 시도할 수 있게 안내한다.
- [x] 입력 화면에 이름, 전화번호, 이메일을 묻는 칸이 없다.
- [x] 시도 키 중복 처리는 화면과 분리한 함수로 두고 단위 테스트가 있다.
