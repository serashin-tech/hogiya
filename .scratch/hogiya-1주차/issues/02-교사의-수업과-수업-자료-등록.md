# 02: 교사의 수업과 수업 자료 등록

**What to build:** 과학 교사가 담당 학급의 수업을 만들고, 제목과 본문으로 된 수업 자료를 추가, 수정, 삭제합니다. 새 수업은 작성 중으로 시작하며 학생 목록에는 나타나지 않습니다. 제목이나 본문이 비어 있는 자료는 저장되지 않고 비어 있는 입력 위치를 알려 줍니다. 공개와 마감 전환은 다음 티켓에서 다룹니다. Spec: S02(등록 부분).

**Blocked by:** 01

**Status:** done

- [x] 교사가 수업을 만들면 공개 상태가 작성 중이다.
- [x] 작성 중인 수업은 학생의 수업 목록에 나타나지 않는다.
- [x] 교사가 자료(제목과 본문)를 추가, 수정, 삭제할 수 있다.
- [x] 제목이나 본문이 비어 있으면 저장되지 않고 비어 있는 입력 칸이 표시된다.
- [x] 교사는 담당이 아닌 과목에는 수업을 만들 수 없다.
