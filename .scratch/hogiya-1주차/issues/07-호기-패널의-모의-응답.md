# 07: 호기 패널의 모의 응답

**What to build:** 복습 화면 오른쪽에 호기 패널이 있고, 왼쪽에서 보고 있는 개념이 바뀌면 패널의 문맥도 바뀝니다. 응답은 함수 한 곳에서 만들고, 1주차에는 개념마다 미리 쓴 설명과 근거가 된 수업 자료의 제목을 돌려줍니다. 연결된 자료가 없는 질문에는 추측하지 않고 "자료의 해당 부분을 다시 확인하거나 선생님께 물어보세요"를 안내하며, 수업과 무관한 질문은 한 문장으로 돌려보내고 현재 개념으로 다시 안내합니다. 응답 함수에 전달하는 입력은 현재 개념과 그 수업의 승인된 자료로 제한합니다. 패널에는 "모의 응답입니다" 표시를 둡니다. 2주차에 이 함수 안만 Claude API 호출로 바뀝니다. Spec: S06.

**Blocked by:** 06

**Status:** done

- [x] 전구 직렬·병렬 개념에서 질문하면 그 개념의 설명과 자료 제목이 함께 나온다.
- [x] 근거 없는 질문은 추측 없이 확인 안내가 나온다.
- [x] 수업과 무관한 질문은 한 문장으로 돌려보내고 현재 개념으로 안내한다.
- [x] 응답 함수를 일부러 실패시켜도 결과 화면과 제출한 답안이 그대로 조회되고 시도 횟수가 늘지 않는다.
- [x] 응답 함수가 받은 입력에 학생 이름, 다른 학생의 답안, 다른 과목의 자료가 들어 있지 않다.
- [x] 패널에 "모의 응답입니다" 표시가 있다.
