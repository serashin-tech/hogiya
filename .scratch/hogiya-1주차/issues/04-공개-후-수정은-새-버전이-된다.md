# 04: 공개 후 수정은 새 버전이 된다

**What to build:** 공개한 문항 세트나 루브릭을 교사가 고치면 기존 것을 덮어쓰지 않고 새 버전을 만들고, 이전 버전은 보존합니다. 이미 낸 시도는 제출 당시의 버전에 연결된 채로 조회됩니다. 대시보드가 어느 버전의 결과를 보여 주는지는 07번 티켓의 표시와 맞춥니다(첫 버전은 최신 버전 기준). ADR 0001. Spec: S03(버전 부분).

**Blocked by:** 03

**Status:** done

- [x] 공개 뒤 문항 지문을 고치면 버전이 2가 되고, 고치기 전에 제출한 시도는 버전 1에 연결된 채로 조회된다.
- [x] 이전 버전의 문항과 루브릭을 조회할 수 있다.
- [x] 작성 중인 수업의 문항을 고치는 것은 새 버전을 만들지 않는다.
- [x] 새 버전으로 새로 푼 시도는 버전 2에 연결된다.
