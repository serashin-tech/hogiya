# 01: 역할 전환과 담당 범위

**What to build:** 상단에서 교사 4명이나 학생 1~20번을 고르면, 고른 사람이 열 수 있는 수업만 목록에 보입니다. 다른 과목 수업이나 다른 학생의 시도를 주소로 직접 열면 거절됩니다. 담당 수업이 없는 국어·영어·수학 교사는 빈 목록과 안내 문구를 봅니다. 이 티켓에 이후 모든 티켓이 쓰는 바탕이 함께 들어갑니다: 테스트 환경, 모의 데이터의 타입 계약(SPEC 공통 약속의 데이터 계약), 접근 판단 함수, 공개 상태인 「전기의 이용」 시드 수업 하나(문항 5개, 개념 2~3개, "검수 전 초안" 표시). 접근 판단은 화면과 분리한 순수 함수 한 곳에서 하고 단위 테스트를 먼저 씁니다. Spec: S01.

**Blocked by:** None (can start immediately)

**Status:** done

- [x] 과학 교사가 같은 학급 수학 수업의 답안 주소를 직접 열면 거절된다.
- [x] 학생이 다른 학생의 시도 주소를 직접 열면 거절된다.
- [x] 학생이 작성 중인 수업을 직접 열면 거절된다.
- [x] 교사 4명 모두 자기 담당 수업 목록만 보인다. 담당이 없는 교사는 빈 목록과 안내 문구를 본다.
- [x] 범위 밖 요청은 "열 수 없는 자료입니다"만 보여 주고 대상이 존재하는지는 알려 주지 않는다.
- [x] 접근 판단 함수의 단위 테스트가 위 사례를 모두 포함하고 통과한다.
